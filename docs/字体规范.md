# 字体规范

游戏文字一律走 [`src/theme/typography.ts`](../src/theme/typography.ts)。禁止业务手写 `fontFamily`。

## 策略

| 层级 | 字体 | 进包 |
|---|---|---|
| **正文 / 局外 HUD** | 系统 `sans-serif`（苹方/黑体） | 否 |
| **展示 + 战斗反馈** | [得意黑 Smiley Sans](https://github.com/atelier-anchor/smiley-sans)（SIL OFL 1.1） | [`fonts/SmileySans-subset.ttf`](../fonts/SmileySans-subset.ttf) |

得意黑只有斜体切割（Oblique），标题/飘字会略斜——这是字型设计。

战斗飘字见 [`combatFloatText.ts`](../src/view/battle/combatFloatText.ts)：伤害/治疗用得意黑；地形加成与减伤用系统字并分色；技能名 / 普攻用得意黑暖金描边字（无底方框），不与地形文案合并。

## 角色

| Role | 字体 | 默认字号 | 场景 |
|---|---|---:|---|
| `display` | 得意黑 | 26 | 胜/负大标题、章节主名 |
| `title` | 得意黑 | 18 | 主按钮、三选一标题 |
| `heading` | 系统黑体 | 18 | 人名、面板顶栏。不用得意黑，避免子集缺字导致一字两形 |
| `combatLabel` | 得意黑 | 15 | 技能名气泡、回合条、战斗提示 |
| `combatFloat` | 得意黑 | 22 | 伤害 / 治疗数字 |
| `ui` / `uiStrong` | 系统 | 14 | 列表主名、局外属性、地形飘字 |
| `body` / `caption` / `micro` | 系统 | 9–12 | 描述、轻提示、角标 |

颜色只来自 [`mvpTheme.ts`](../src/view/mvpTheme.ts) 的 `C`。

## API

```ts
import { makeText, textStyle } from '@/theme/typography';

makeText('胜利', 'display', { fill: 0xfff4d8, stroke: 0x7a4a10, strokeThickness: 5 });
makeText('点击奖励查看说明', 'caption', { fill: 0xb8b8a8 }); // 系统字
```

## 加载与子集

```bash
# 源文件：tools/font-src/SmileySans-Oblique.ttf（gitignore）
npm run font:subset
```

[`FontLoader.loadGameFonts`](../src/core/FontLoader.ts) 只 load 展示字体；与图片 bundle 并行。失败则展示角色也回退系统字。

加了新的**展示向**中文文案后重跑子集。正文新增字不影响字体包。
