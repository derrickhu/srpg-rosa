# bgm_hub · 大厅

在 [suno.com](https://suno.com) 用下面两段生成，选 **instrumental**。导出 mp3 后放到仓库外 `game_assets/srpg-rosa/audio/bgm/hub.mp3`，确认首尾能循环再拷进 `audio/bgm/hub.mp3`。

目标：约 90 BPM，大厅四 Tab 共用。西欧中世纪战棋营地，不是东方仙侠。

上一版带了 `guzheng-like zither`，Suno 会往中式走。这一版去掉古筝/古琴/二胡，锁死鲁特琴 + 欧洲竖琴 + 木笛。

## Style

```
western medieval fantasy, european tactical RPG, fire emblem camp, renaissance lute, celtic harp, wooden recorder flute, light tabor drum, cozy castle hall, bright and warm, instrumental, no vocals, no guzheng, no erhu, no pentatonic chinese scale, no east asian, loop-friendly, 90 BPM, D major
```

## Lyrics / 结构（整段贴进歌词框）

```
instrumental, no vocals
no guzheng, no erhu, no chinese pentatonic, western instruments only

[Intro]
soft renaissance lute ostinato, one recorder flute phrase answering, very light tabor

[Loop A]
lute plays a short 8-bar european folk motif, celtic harp sparkles every 4 bars, flute holds long notes

[Loop B]
same western motif, slightly fuller tabor, still quiet, no drums drop, no east asian ornaments

[Outro]
return to the intro lute ostinato so the end matches the start
```
