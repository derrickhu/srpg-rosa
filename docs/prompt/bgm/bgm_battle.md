# bgm_battle · 普通战斗

在 [suno.com](https://suno.com) 用下面两段生成，选 **instrumental**。导出 mp3 后放到仓库外 `game_assets/srpg-rosa/audio/bgm/battle.mp3`，确认首尾能循环再拷进 `audio/bgm/battle.mp3`。

目标：约 128 BPM。同一套西欧乐器，密度拉高；Boss 节点 v1 也复用这一首。

```
western medieval fantasy battle, european tactical RPG, fire emblem skirmish, driving renaissance lute ostinato, celtic harp stabs, wooden recorder flute lead, light war tabor and snare, energetic but chamber-sized, instrumental, no vocals, no guzheng, no erhu, no pentatonic chinese scale, no east asian, no full orchestra, loop-friendly, 128 BPM, D minor
```
