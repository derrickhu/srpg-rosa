# bgm_deploy · 布阵

在 [suno.com](https://suno.com) 用下面两段生成，选 **instrumental**。导出 mp3 后放到仓库外 `game_assets/srpg-rosa/audio/bgm/deploy.mp3`，确认首尾能循环再拷进 `audio/bgm/deploy.mp3`。

目标：约 100 BPM。和大厅同一套西欧乐器，密一点，像在地图上摆骑士。

## Style

```
western medieval fantasy, european tactical RPG, fire emblem prep, renaissance lute, celtic harp, wooden recorder flute, light marching tabor, expectant war council, instrumental, no vocals, no guzheng, no erhu, no pentatonic chinese scale, no east asian, loop-friendly, 100 BPM, D major
```

## Lyrics / 结构（整段贴进歌词框）

```
instrumental, no vocals
no guzheng, no erhu, no chinese pentatonic, western instruments only

[Intro]
lute pulse in 4, soft tabor on 2 and 4, recorder flute enters on bar 5

[Loop A]
walking lute pattern, celtic harp accents, flute plays a short european call

[Loop B]
same pulse, slightly busier tabor, still no battle drums, motif repeats so it can loop

[Outro]
strip back to lute pulse matching the intro
```
