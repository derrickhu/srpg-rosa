# bgm_shop · 补给点

在 [suno.com](https://suno.com) 用下面两段生成，选 **instrumental**。导出 mp3 后放到仓库外 `game_assets/srpg-rosa/audio/bgm/shop.mp3`，确认首尾能循环再拷进 `audio/bgm/shop.mp3`。

目标：约 88 BPM。西欧路边补给帐篷，比大厅更轻。

## Style

```
western medieval fantasy market, european tactical RPG, fire emblem armory, renaissance lute, celtic harp, wooden recorder flute, very light finger snaps and shaker, gentle supply tent, instrumental, no vocals, no guzheng, no erhu, no pentatonic chinese scale, no east asian, loop-friendly, 88 BPM, G major
```

## Lyrics / 结构（整段贴进歌词框）

```
instrumental, no vocals
no guzheng, no erhu, no chinese pentatonic, western instruments only

[Intro]
two-bar renaissance lute figure, one recorder flute note, almost empty

[Loop A]
lute plays a simple european market motif, flute hums in the gaps, celtic harp every 8 bars

[Loop B]
same motif, add a quiet shaker, no drums, keep space

[Outro]
drop to the two-bar lute figure so it loops into the intro
```
