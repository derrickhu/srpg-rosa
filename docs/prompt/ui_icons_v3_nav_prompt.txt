为什么要 --min-spill 140：魂晶是紫水晶，紫和品红键色在色相上挨着。默认参数下
despill 把「红蓝双高、绿偏低」一律当溢色压平，整块紫会变成白配深蓝。实测这张图里
素材本身的品红度最高 133、键色底 237~245，取 140 卡在中间。换配色前先重新量一次。

背包页魂晶卡片的 💎。魂晶此前**根本没有图标**，只有文字。
