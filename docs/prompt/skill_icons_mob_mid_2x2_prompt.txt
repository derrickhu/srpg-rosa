## 这一组是**敌方杂兵**技能，材质分界要和前两类分开

已有的两条分界是：常规技能 = **金属**（钢、铁、盾），临时技能 = **自然物**
（草原是草药蜂木，密林是树皮松脂荆棘）。杂兵技能占第三类：**生物性器官与凶器**
——孢子囊、狼头、吹管、鳄口。它们不是人造的工具，也不是玩家采到的植物，
是**怪身上长出来的东西**。玩家在面板上看到这一类，应该读到「这是它的一部分」。

所以这一组里**不要出现**：制式盾牌、剑、锤、铁质武器（那是常规技能的符号）、
药瓶、绳索、旗帜、火把（那是临时技能的符号）。

## 四个技能的语义（改 prompt 前先看 src/data/skillCatalog.ts 的杂兵技能段）

    spore_spray  孢子喷散  第 2 章喷孢囊：半径 1 孢子雾 + 中毒 3/回合 ×2
    wall_ram     撞阵      第 3 章巡墙狼骑：正好隔 1 格突进 + 减速 3 ×2
    venom_dart   淬毒吹箭  第 4 章吹箭虫：3 格内点杀 + 中毒 3/回合 ×2
    mire_bite    毒沼撕咬  第 4 章沼行鳄：邻格重咬 + 中毒 5/回合 ×2

## 关键约束

- **三个带毒的技能不能都画成同一坨绿雾。** 区分靠**载体**：孢子是一团扩散的雾囊、
  吹箭是一根直的针、撞咬是一张咬合的嘴。毒只是它们共同的颜色，不是共同的形状。
- 第 4 章那两个（吹箭 / 撞咬）毒量不同（3 对 5），但**图标不承担数值**，
  别试图画出「更毒」，面板上有数字。
- `wall_ram` 是这一组唯一不带毒的，它必须一眼看出是**冲撞**而不是中毒——
  所以它走灰绿狼头 + 土金冲击纹，全组唯一的暖色。
- **禁止紫色**（本项目硬禁，见美术风格圣经 §1.3）。毒走脓黄绿，不走紫。
