# 大厅四页标题底

页名居中叠在这四张空心底上。图里不写字——「招募 / 角色 / 冒险 / 副本」用系统黑体在代码里画。

不要再用全站同一根金绶带。四张必须**外形和主色都不同**，只共用：近黑粗描边 `#1A1410`、中央米白空井 `#FCFCF6`、平涂卡通、金色只做细描边。

## 共用禁令

NO TEXT, no letters, no Chinese characters, no numbers, no runes, no fake glyphs, no watermark.
Background must be 100% solid flat MAGENTA `#FF00FF`.
Do not use magenta / hot pink anywhere on the plaque itself.
Empty cream well in the center must stay blank — large enough for two chunky Chinese characters.
