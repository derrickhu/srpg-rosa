# 新手引导 UI 零件

对标休闲战棋常见的轻引导：白底细框气泡 + 左侧讲解人 + 白手套。不要厚羊皮纸、不要金、不要角花。

产出：

| 文件 | 比例 | 入库尺寸 | 用途 |
|---|---|---|---|
| `tutorial_guide` | 3:4 | 高约 200 | 左侧讲解人半身，叠在白气泡左边 |
| `tutorial_hand` | 1:1 | 长边 128 | 白手套，食指指向左上 |

对话框不再出图：运行时用 Graphics 画白底圆角 + 左侧小三角尾巴。

入库前必须缩小。母版原分辨率不要进主包。

## 共用

NO TEXT, no letters, no Chinese, no numbers, no watermark.
Background 100% solid flat MAGENTA `#FF00FF`.
Do not use magenta on the object itself.
Chunky cartoon, thick near-black `#1A1410` outline, flat fill + one cel shade.
No gradients, no photo grain.

讲解人按战场角色那套 1.5 头身吉祥物来画，不要抄别的游戏的狐耳娘。
手套是纯白卡通连指手套，不是肉色手。
