# 章节卡奖励壳

冒险卡中间不再铺一整块米白井。奖励区分成画出来的零件，叠在冷蓝灰卡壳上。

金只给底部主 CTA。这里禁止金色角花 / 金绶带。

产出：

| 文件 | 比例 | 用途 |
|---|---|---|
| `chapter_plaque` | 3:4 | 通关奖励一列的羊皮纸牌 |
| `chapter_strip` | 16:9 | 旧本关横条，已弃用 |
| `chapter_repeat_title` | 16:9 | 本关奖励标题牌，居中，空井叠字 |
| `chapter_repeat_frame` | 4:3 | 本关奖励魂晶框，与标题同宽居中 |
| `chapter_ribbon` | 16:9 | 「通关奖励」分区绶带（石蓝，不是金） |
| `chapter_star_on` / `chapter_star_off` | 1:1 并排 | 点亮 / 空心星，叠在每列牌顶 |

## 共用

NO TEXT, no letters, no Chinese, no numbers, no runes, no watermark.
Background 100% solid flat MAGENTA `#FF00FF`.
Do not use magenta on the object itself.
Chunky cartoon, thick near-black `#1A1410` outline, flat fill + one cel shade.
No gradients, no photo grain, no gold `#EEC462`.

羊皮纸主色用旧纸 `#D8C8A4`，不要 `#FCFCF6` 那种刺眼米白。
