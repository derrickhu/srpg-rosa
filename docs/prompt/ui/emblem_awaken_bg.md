# 纹章觉醒 · 夜殿背景

大厅养成庆祝的全屏底。图里不写字。竖版 9:16，中央留给叠上去的圆形徽记。

## 画面

一座深酒红到靛蓝的夜殿，不是白天厅堂，也不是战斗草地。

- 上半：近黑靛蓝 `#140818` 穹顶，几条粗而短的金光柱从正中往外散，平涂色块，不要体积光
- 下半：暗红石台，只有一大块几何台阶，不要砖缝、浮雕、柱头细节
- 正中空出一块暗圆，给运行时徽记留位置
- 左右各一块扁平的暗金立柱剪影，形状要大、边要少
- 地面一条浅金反光带，平涂，不要倒影
- 整体偏暗，金只做点睛，不要把画面做成白天神殿
