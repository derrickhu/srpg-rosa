# 铭刻印章

Boss 首杀页人和纹章中间那枚「铭刻」印。图里不写字——「铭刻」两个字用游戏字体叠，和胜利横幅同一套做法。

上一版按觉醒徽生，出来是空心金环加四颗方齿；用金币图标当参考又出成立体铜钮。定稿是不带参考图的实心花瓣蜡印：六瓣金蜡、米白空井、底沿两滴蜡。

## 画面

一张单独的圆形蜡印章，正面正对镜头，几乎铺满画幅。

- 本体：厚厚一饼封蜡，金币那种黄 `#EEC462`，像刚压好的蜂蜜蜡章
- 外沿：软而不规则的蜡边，底沿两滴刚凝固的烛蜡，蜂蜜那种黄
- 明暗只两档：右下暗金 `#D8A038` 新月，左上浅金高光
- 正中压出一圈米白井 `#FCFCF6`，空着，留给两个字；井口一道细金环像印痕
- 近黑描边 `#1A1410` 要粗，和金币图标同一套线

风格参考用 `images/ui/icon_gold.png`：只要它的描边和金币黄平涂，不要抄中间那颗星。
