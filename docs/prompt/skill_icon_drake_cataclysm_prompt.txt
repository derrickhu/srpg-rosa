这是**敌方技能皮肤**图标（src/data/enemySkillCatalog.ts 的 drake_cataclysm），
底层实现是 dragon_breath：直线穿透 + 按目标最大血量收费 + 残血处决。
它不进玩家商店，也不在可学列表，所以配色不迁就玩家技能的分组规则，
要一眼看出「这不是我的招」。

要和三个东西分开，优先级从高到低：

1. **同为直线的第三章「破阵冲撞」**（skill_bloodfang_breach）。那个是钢青色的一条
   等宽贯穿线；这个必须是**张开的锥形**——窄口喷出、越远越宽。玩家分不清
   「一条线」和「另一条线」，但分得清「从嘴里喷出来的」和「整个人撞过来的」。
   所以这张图标的成败全在**锥形张开**这一件事上，不在颜色。

2. **第二章「燎原咒火」**（skill_bloodfang_wildfire）。那个是暗红咒火、竖直向上窜的
   火舌；这个是白热吐息、**横向**喷射。同为火，靠「方向 + 色温」分：
   咒火是邪的（暗红），龙息是烫的（白热到橙红）。

3. **玩家的炎弹 / 松脂火把**。玩家那两个是暖橙小火，尺度是「一发」；
   这个要读起来是**一片**，覆盖感要压过它们。

硬禁：不要洋红、不要粉、不要紫（背景是洋红抠色键，火焰内芯用近洋红的红会被抠掉一块）。
第二章咒火用了 #C2185B 做内芯，这张**不要跟**——那个是暗底上的小面积内芯，
而这张的高亮面积大得多，贴近键色会直接崩边。白热内芯用纯白到浅黄。
