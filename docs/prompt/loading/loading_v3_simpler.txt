# Loading v3 — 同一构图，按圣经减细节

上一版（v2）场景成立，但画得太满：木纹、苔藓、碎草、营帐骷髅、石块裂纹。
这一版锁《美术风格圣经》§3：平涂、每物 2–3 色、树冠三层圆丘、角色 4–6 色。
参考画法母版：现役 `images/ui/loading/loading_splash.jpg`（空、平、少道具）。

共用禁令：
- 不要材质：木纹、布纹、石裂纹、苔藓点、碎叶子、草尖、光斑、渐变、厚涂
- 地形不描粗黑框；角色 / 龙 / 望楼才描近黑厚边
- 上三分之一天空中央留空给 Logo；下三分之一少东西给进度条
- 图里禁止任何文字

A 巨龙追击：角色减到 4 个（剑士、骑兵、弓手、盾卫）。山是两三块平涂岩石，不要碎石和扬尘。
B 纯密林：树冠是三层圆丘，路是一条平涂土黄带，石祠是两色方块，着火是一团平涂橙。不要蕨、不要树皮。
C 草原围殴：右边禁止营帐 / 骷髅桩 / 红旗。左边最多一座简化木望楼，右边是空丘陵。不要黏泥、不要蘑菇。
