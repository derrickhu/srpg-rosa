# 第五章 Boss「龙王·安卡洛斯」—— 四方向行走 sheet（generate2dsprite player_sheet, 4x4）
#
# 关卡：src/data/stagesMvp.ts `c5_7`「龙王」，animSet `drakelord`
# 参考图：art/sprite-runs/bloodfang/walk/raw-sheet.png —— 同时锁风格和 4x4 布局
#
# ## 为什么终章 Boss 值得一整套图集
#
# 这是全游戏唯一的收尾高光，档位上和第一章酋长对等（酋长有四向行走 + 两向攻击）。
# 其余四章的精英走单帧，杂兵走单帧——预算全压在这里和另外三个 Boss 身上。
#
# ## 体型
#
# boss 在运行时还会 ×1.3（BattlePlaybackView `if (u.boss) body.scale.set(1.3)`），
# 所以这里画**正常单位的格内占比**，靠轮廓厚重体现压迫感，不要画满格。
# 画满格 + 运行时 1.3 会直接溢出到相邻格子。
#
# ## 配色
#
# 本章签名色是熔岩橙红 + 黑曜石，四只杂兵是 黑曜+橙裂纹 / 橙红 / 灰黑 / 苍白。
# 龙王必须压得住这四只：走**最深的黑曜主体 + 最亮的白热橙**，明度两极都比杂兵更极端。
# 白热色（#FFD9A0）只出现在喉部和翼膜边缘——那是「灭世龙息」的蓄能位置，
# 让技能来源在静止帧里就有交代。
#
# 钢青、蓝、绿一律不要：绿会撞前四章的兽人，蓝会撞我方盾卫和法师。
#
# ## 键色安全
#
# 主色是黑曜黑、橙红、白热橙、暗铁，到品红 #FF00FF 的色距均 > 200，
# 远超抠色阈值 100/150。但仍必须在 prompt 里明文禁掉粉/品红/紫罗兰。
