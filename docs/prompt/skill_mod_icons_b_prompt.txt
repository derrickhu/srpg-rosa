关键约束（改 prompt 时别丢）：
- 和第一批九个**必须像同一套**：同样的描边粗细、同样的简化程度、同样的平涂厚描边。
  参考图只用来对齐画法，题材一个都不要抄。
- 与第一批的形状不许撞：
  haste 是**带翅膀的靴子**，不要再画沙漏（quick 已占）；
  bloodthirst 是**剑穿过心脏**，不要画成 siphon 那种「心 + 液滴」；
  lasting 是**圆钟表盘**，不要画沙漏；
  splash 是**冲击环 + 甩出的水滴**，不要画成 overwhelm 那种实心星爆；
  execute 是**骷髅**，不要再画第三把剑（sharpen 完整剑、rout 断剑已占）。
- 每个图标必须是**一整块连通的剪影**，不许有飘在旁边的独立小部件——16px 下读不出来，
  切图也会因为块数对不上名字数而失败。
- 玩家要在 0.5 秒内从三张卡里挑一张，图标是第一眼看到的东西，比文字先到。

生图实测偏差（下一个人抄的时候知道哪里模型不听话）：
- 一次就出齐 11 个，风格和第一批对得上，参考图这招有效。
- **布局按 4/4/3 出的，切图要分两刀**：上两行走 `--grid 4x2`（chevron、水滴这类
  分离部件必须用 grid 模式，连通域会把一个图标数成好几块），最后一行三个各自都是
  连通的，直接走默认连通域模式。
- **signature 默认参数会被吃掉 70% 的像素**：深红离品红太近，和当年的 overwhelm 同一个坑。
  实测素材自身品红度 p99=93，真溢色边到 255，取 `--min-spill 120` 卡在中间，
  校正率从 70.2% 降到 0.5%。
- `lasting` 出来偏「绿色水滴」而不是「钟表盘」，16px 下读作一个绿点。26px 以上没问题，
  真要重做时把表盘画得更大、把那颗水滴缩小。
- `splash` 的冲击环出成了缺口很大的「C」形，比预期更像字母。可接受，但重做时应要求
  「环的缺口不超过四分之一圈」。
- `bloodthirst` 是全套里最弱的一个：竖着的剑让包围盒变成 46x64，等比缩到 40px 后
  心脏只剩不到 30px 宽，16px 下退化成一个红点。它是史诗档、恰恰是最该亮眼的位置。
  下次重出整套时把剑改成**斜插**、心脏放大占满宽度。
