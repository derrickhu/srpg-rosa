#
# ## 剪影：为什么是「竖立的臃肿囊体」
#
# 第四章四只杂兵已经占掉：巨手（无身体）、宽伞飞虫、横长四足、扁壳巨钳。
# 精英塔玛是人形兽人。蛭后必须避开这五个，所以走**竖立的水滴形囊体**：
# 上半身鼓成一个巨大的卵囊，下面两条粗短腿，前面两条粗抓肢。
# 40px 下它是全章唯一一个「上宽下窄的竖直块」，和横长的鳄、扁宽的蟹正好反着。
#
# 不要画成多足贴地爬行：一是会和沼行鳄撞剪影，二是四方向行走的多足很难在
# 16 格里保持一致（龙王那次已经验证双足最稳）。
#
# ## 体型
#
# boss 在运行时还会 ×1.3（BattlePlaybackView `if (u.boss) body.scale.set(1.3)`），
# 所以这里画**正常单位的格内占比**，靠轮廓臃肿体现压迫感，不要画满格。
# 画满格 + 运行时 1.3 会直接溢出到相邻格子。
#
# ## 配色
#
# 本章签名色是脓黄绿 + 近黑，四只杂兵是 近黑 L12 / 亮酸黄绿 L67 / 苔绿 L33 / 灰绿 L66。
# 蛭后必须压得住这四只：主体走**比泥沼手还深的沼黑**（#1E2119，L10），
# 囊袋走**比吹箭虫还亮的胆绿**（#B8D63C，L72），明度两极都比杂兵更极端。
#
# 胆绿只出现在囊袋和口环内缘——那是「腐沼瘟息」的蓄能位置，
# 让技能来源在静止帧里就有交代（同龙王的喉部白热）。
#
# 橙红一律不要（那是第五章的签名）；蓝、钢青、纯绿也不要：会撞我方盾卫、法师和前几章兽人。
#
# ## 生图后必做：换行
#
# 这一版生图把第 2、3 行**画反了**——第 2 行朝右、第 3 行朝左，而管线按
# down/left/right/up 的行序打标签。不换行的话，蛭后往左走时会朝右转。
# 修法不是重生图（其余 15 格都是好的），而是交换两行：
#
#   from PIL import Image
#   im = Image.open(<raw>).convert('RGBA'); W, H = im.size; ch = H // 4
#   r2 = im.crop((0, ch, W, 2*ch)); r3 = im.crop((0, 2*ch, W, 3*ch))
#   out = im.copy(); out.paste(r3, (0, ch)); out.paste(r2, (0, 2*ch))
#
# 教训：左右行序是模型最常搞反的一项，**每张 4x4 行走表处理前都要先肉眼核对
# 第 2、3 行的朝向**，别等打包完在游戏里看出来。
#
# ## 键色安全
#
# 主色是沼黑、胆绿、暗铁，到品红 #FF00FF 的色距均 > 200，远超抠色阈值 100/150。
# 但仍必须在 prompt 里明文禁掉粉/品红/紫罗兰——这一章题材（腐坏、瘟疫）最容易被模型
# 自动补成紫色。
