# 生图 prompt 约定

## 写新 prompt

1. 先读 [美术风格圣经](../美术风格圣经.md)，尤其 §2.1 配色编码、§4.1 怎么避免"普通"、
   §4.3 已知色彩冲突。
2. 风格段落**原样粘贴** [`_style_block.txt`](./_style_block.txt)，不要自己重写措辞。
   风格描述只有一处会变，就是那个文件。
2.5. 行走 sheet 的迈腿段落**原样粘贴** [`_walk_motion_block.txt`](./_walk_motion_block.txt)。
   这一段单独抽出来是因为踩过坑：早期 prompt 各写各的，写 "slight body bob down" 的剑士朝下
   只有 6.2% 腿部剪影差异、弓手更是低到 2.8%，走起来像雕像平移；写 "heavy" 的血牙是 23~52%。
   验收方法见[美术管线](../美术管线-AI-sprite.md#行走动作的验收标准)，低于 15% 就重出。
3. 在风格段落之后补角色专属的三行：主色（查 §2.1 并做差异检查）、剪影一句话、唯一记忆点。
4. 布局、朝向、帧数等**结构性**要求单独写，别和风格混在一段——混在一起时模型容易
   把参考图的布局也一起抄过来（`unit_bloodfang_attack_*` 就踩过这个坑）。

## 命名

- 单位：`unit_<集合id>_<动作>_prompt.txt`
- 特效：`vfx/<特效id>.md`，一律放这个子目录。正文之外还要记下**运行时参数**
  （anchor / mode / cells）和**生图实测偏差**，下一个人抄的时候才知道哪些地方模型会不听话。
  规则与五步管线见《[特效圣经](../特效圣经.md)》。
- UI / 场景：`<用途>_prompt.txt`

## 场景、地形、UI 的额外约定

这几类不走 `generate2dsprite`，管线短得多，但有三条固定做法：

1. **键色一律用品红 `#FF00FF`**，不要用浅灰。地形里有灰色城墙、UI 里有灰色齿轮，
   浅灰底会被抠像连着素材一起吃掉。
2. **多个素材出在一张 sheet 里**，用
   [`scripts/split-tile-sheet.py`](../../scripts/split-tile-sheet.py) 按连通域切开，
   再跑 `despill-magenta.py` 清紫边。一次出全套是为了让它们的线条粗细和简化程度一致——
   上一版图标是分几次生的，摆在一行里明显像凑的。
3. **写清楚游戏内的实际显示尺寸**（图标 15~22px、地形格 40px），并据此要求低频。
   模型默认会按海报的信息密度画，不说就一定过细。
4. **素材配色里有紫/粉时，切图前先量键色可分性**，再给 `--key-threshold` 和 `--min-spill`
   定值。紫和品红挨着，默认参数会把紫色素材连着键色一起处理掉——魂晶水晶第一次切出来
   紫全没了，成了白配深蓝。量法见[管线文档](../美术管线-AI-sprite.md)。
5. **同一个图标会压在几种底色上时，prompt 里要把每种底色的十六进制都写出来**。
   底栏 tab 未选中在 `#465470`、选中在 `#EEC462` 上，不讲清楚模型会挑一个金色填充，
   到了选中态就整个消失。

## 现役版本与它取代了谁

| 现役 | 取代 | 主要变化 |
|---|---|---|
| `battle_bg_v9` | `battle_bg_v5` / `v6` | 彻底去掉天空，草地转暖黄绿以避开弓手色相 |
| `terrain_v4_3x2` | `terrain_v3_3x2`（已删） | 去掉黑描边，键色改品红，明度序写进 prompt |
| `ui_icons_v2` | `toolbar_icons_2x2` | 九个图标一次出齐，三种药剂共用瓶型 |
| `ui_icons_v3_nav` | 底栏与节点条的 emoji | 五个 tab + 魂晶 + 锁 + 补给 + BOSS，要求同时压得住深底与金底 |
| `chapter_grassland` | 章节卡的纯色底 | 第 1 章插图，2.4:1 扁画幅，重点压中间横带留裁切余量 |
| `logo_v2` | `home_logo_*` | 去掉金属高光与斜面，改平涂 + 粗描边 + 米白外圈 |
| `mobs_ch1_v1` | 第一章敌方共用四职业美术 | 四只魔物一张 2x2，只出静止姿势，呼吸与出手位移交给代码 |

被取代的文件按下面这条规矩保留，`terrain_v3` 是唯一例外——它对应的六张贴图已经不在仓库里，
留着也锚不住任何东西。

## 关于圣经之前的旧 prompt

`unit_bow_walk_sheet` / `unit_bloodfang_*` / `vfx_savage_roar` 写于圣经之前，各自
重写了风格描述，措辞不完全一致（比如描边有的写 "dark brown" 有的写 "dark"）。

**这些文件保持原样不动**——它们是当前线上资产的复现锚点，改了就对不上已生成的图。
等哪天要重做对应资产时，再顺手换成引用 `_style_block.txt`。新资产一律走新约定。
