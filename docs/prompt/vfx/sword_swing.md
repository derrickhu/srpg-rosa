# sword_swing — 剑士挥砍的逐帧刀影

## 为什么要这套图

原先剑士的挥砍是拿 `images/fx/slash_blade.png`（**一整把带护手和握柄的剑**的侧视图）
沿弧线反复钉下去、每次转一点角度。屏幕上看到的就是一把剑连着柄在角色身边打转，
读不出「挥」这个动作——单张静态图沿路径平移永远做不出挥砍，挥砍的信息量在
**刀身角度的变化**里，而那正是单图运动丢掉的东西。

所以改成逐帧：每一帧是刀在挥击轨迹上的一个不同姿态，加上逐渐累积的刃弧残影。

## 规格

- 3x3 网格，9 帧，纯黑底（`#000000`），additive 素材
- 每格正方形，帧之间不要留白线、不要网格线、不要边框、不要文字
- 素材一律画成**朝右（+X）挥出**，运行时再转到实际方向

## 形态

一记从右上往左下的斜劈，刀身全程可见：

- **帧 1–2**：刀从右上进入，刃口刚亮起，残影只有一小段细金弧
- **帧 3–5**：刀扫到中段，刀身最亮，身后拖出一条完整的金橙刃弧（这三帧最亮）
- **帧 6–7**：刀扫出到左下，刃弧变宽、开始转成余光
- **帧 8–9**：刀已离画，只剩逐渐淡掉的弧和几点飞散火星

## 颜色

- 刀身：银灰到米白，刃脊一条更白的高光（对齐 `images/units/sword.png` 那把阔直刃）
- 刃口与残影：金橙（剑士的族色），靠近刀身处近白，往外转深橙
- 火星：小而少，金橙，只在后两帧
- 禁止：漫画黑描边、弯刀、纯黄光刃、护手和握柄的细节（这是刀影不是道具图）
