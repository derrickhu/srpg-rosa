# MVP 与策划全案差异清单（供 v1.1+ 对齐）

本文件记录当前 **MVP 验证版** 相对 [无尽纹章-战棋休闲IAA小游戏策划案.md](./无尽纹章-战棋休闲IAA小游戏策划案.md) 的刻意裁剪与实现差异，便于后续迭代收敛。

## 玩法范围

| 策划项 | MVP 现状 |
|--------|----------|
| 棋盘 5×6 | 棋盘 **随关卡配置**：`StageDefMvp.terrain` 矩阵决定宽高（例：第 1 关 **6×7**、第 2 关 **8×9**、第 3 关 **9×10**）；地形仍为 **平原 + 高地** |
| 每方最多 6 单位 | 每方最多 **3** 单位 |
| 6 基础兵种全开 | **4** 种数据（剑、弓、骑、盾），开局手牌仅剑/弓/盾各 1；骑主要经商店或关卡理解三角 |
| 完整地形表 | 仅 **平原 + 高地**；高地仅 **攻击方 +25% 伤害** |
| 被远程打高地减伤 | **未做** |
| 背刺、协战 | **未做** |
| 战斗微操（集火、撤退） | **未做**，全自动；已有 **简化技能 + 战斗过程回放**（逐格移动、技能名与伤害飘字） |
| 三星、回合评价 | **未做** |
| 失败激励视频复活 | **未做**；失败可「返回布阵」或「整局重来」 |
| 商店三标签 + 刷新/锁定/视频 | **仅招兵三选一**；可「不购买」进下一关 |
| Roguelike 死亡清零 | MVP 为 **固定 3 关线性**；整局重来等价于重开 |
| 局外成长、图鉴、每日、社交 | **未做** |
| IAA 真实接入 | **未做**；[`src/platform/wxPlatform.ts`](../src/platform/wxPlatform.ts) 保留键名占位 |

## 数值与规则

| 策划项 | MVP 现状 |
|--------|----------|
| 克制倍率 1.5 / 0.7 | 使用 **1.25 / 0.85**（便于拉长战斗便于观察） |
| 弓手「直线贯穿」等 | 普攻为 **曼哈顿射程 ≤3**；另有简化 **穿透箭**（四向射线选线，55% 攻击力多段） |
| AI 治疗、复杂被动 | **无**；盾卫仅有 **嘲讽**（敌优先打射程内盾卫） |
| 移动地形消耗（河/林） | **无**，移动力仅受格子阻挡 |

## 技术说明

- 战斗为 **同步演算** + **事件回放**：`BattleReport.events` 含 `moveStep` / `skillCast` 等，开战后经 `BattlePlaybackView` 播放再进结算。
- 布阵交互为 **点选兵种再点格子**（非拖拽），以降低首版交互成本。

## 建议下一迭代优先级

1. 战斗过程可视化（移动/攻击 tween + 战报面板）。
2. 失败复活与至少 1 个真实激励广告位。
3. 商店刷新与金币曲线表。
4. 恢复策划中的三星或简化「挑战目标」。
